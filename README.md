# Sonara

Локальный музыкальный плеер на Electron: треки из ваших папок, плейлисты, "Моя волна" и авто-обновление через GitHub Releases.

## Возможности

- Сканирование локальных папок (mp3, flac, wav, ogg, m4a, opus) с метаданными и обложками.
- Вкладка **Треки** с переключателем вида **сетка ↔ список** (выбор сохраняется).
- **Плейлисты** — создание, редактирование, удаление, добавление треков.
- **Моя волна** — бесконечный персонализированный поток на основе истории прослушиваний и лайков.
- **Авто-обновление** — фоновая проверка GitHub Releases, уведомление в углу, кнопка "Обновить" с прогрессом загрузки и установкой при перезапуске.
- Тёмная и светлая тема, регулировка громкости, очередь воспроизведения, поиск.

## Разработка

```bash
npm install
npm start
```

## Сборка релиза

Локально:

```bash
npm run build       # собрать без публикации
npm run publish     # собрать и опубликовать в GitHub Releases (требует GH_TOKEN)
```

В CI публикация выполняется автоматически при пуше тега `vX.Y.Z`:

```bash
git tag v0.2.0
git push origin v0.2.0
```

GitHub Action соберёт Sonara-Setup-X.Y.Z.exe, latest.yml и blockmap, выложит их в Releases. Установленные клиенты увидят уведомление об обновлении в течение часа.

## Структура

```
src/
  main/        — основной процесс Electron (окно, IPC, библиотека, апдейтер)
  preload/     — preload-скрипт с безопасным API
  renderer/    — UI (HTML/CSS/JS, без фреймворков)
.github/
  workflows/release.yml — публикация релизов
build/        — иконки для electron-builder
```
